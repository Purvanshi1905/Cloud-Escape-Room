☁️ Cloud Escape Room

An immersive, AWS-themed virtual escape room built to combine learning, teamwork, problem-solving, and gamification into one interactive experience. Teams progress through multiple challenge rooms by solving technical puzzles across different domains, ultimately restoring a compromised cloud infrastructure.

🚀 Overview

Cloud Escape Room is a browser-based game designed for students and tech enthusiasts.
Participants enter as teams, solve domain-based challenges, unlock rooms, and compete in real-time on a live leaderboard.

The project transforms traditional technical quizzes into a cinematic game experience with:

🎮 Interactive gameplay
🧠 Story-driven missions
🏆 Real-time leaderboard
🔊 Sound effects & transitions
💜 Modern animated UI
☁️ AWS cloud concepts integration
🎯 Game Flow:-

Welcome Screen
→ Team Login
→ Mission Brief
→ Room 1 – Web Development
→ Room 2 – Cybersecurity
→ Room 3 – Competitive Programming
→ Room 4 – Graphic Design
→ Room 5 – AI / ML
→ AWS Final Challenge
→ Leaderboard & Winner Ceremony

🧩 Rooms & Challenges:-

🌐 Room 1 – Website Crash

Fix the broken frontend system by solving HTML/CSS/Web Development puzzles.

🔐 Room 2 – Security Breach

Identify vulnerabilities, encryption concepts, and cybersecurity basics.

💻 Room 3 – Logic Core

Competitive programming and logical reasoning challenges.

🎨 Room 4 – Design Vault

Graphic design and UI/UX-based visual problem solving.

🤖 Room 5 – AI Control System

Artificial Intelligence and Machine Learning concepts.

☁️ Final AWS Dashboard

Teams analyze all previous clues to identify the correct AWS cloud service and restore the system.
